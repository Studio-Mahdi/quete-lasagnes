# La Quête des Lasagnes 🍝

**Serious game de gestion financière** : Mia, une étudiante, rouvre le restaurant de ses parents pour leur offrir la retraite qu'ils méritent. Du sauvetage de la trattoria à la construction d'une marque, le joueur apprend la comptabilité en vivant chaque décision.

**Jouer** : https://studio-mahdi.github.io/quete-lasagnes/

## Le jeu

- **15 chapitres** : capital, charges fixes, seuil de rentabilité, BFR, amortissement, bilan, TVA, compte de résultat, marge, stocks, provisions, emprunt, trésorerie vs profit, EBE, analyse finale
- Un casting d'alliés et d'ennemis, des embûches, des trophées, un certificat
- Réservé aux étudiants invités (code de promo requis à la connexion)

## Techniquement

Application web statique (HTML/CSS/JS vanilla sans framework, aucune dépendance), connectée à une API Google Apps Script. Interface responsive, sons générés en WebAudio, sauvegarde par code email.

*Projet pédagogique — usage en classe de gestion.*
